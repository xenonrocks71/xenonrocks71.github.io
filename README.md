# Mayur Patil - Portfolio Website

Personal portfolio website of **Mayur Patil**, Software Engineer & AI Systems Developer.  
Live at [https://mayurkpatil.in/](https://mayurkpatil.in/)

## 🚀 Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router, Static Export)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4, Vanilla CSS Design System Tokens
- **Animations:** Framer Motion, GSAP, Smooth Scroll (Lenis)
- **Deployment:** GitHub Pages via GitHub Actions

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build static production bundle
npm run build
```

## 🌐 Custom Domain & Deployment

- Automated CI/CD pipeline configured via GitHub Actions (`.github/workflows/deploy.yml`).
- Serves directly on custom domain `https://mayurkpatil.in/` using GitHub Pages.
